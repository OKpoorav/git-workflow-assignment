My command log - Git workflow assignment (project folder: git-assignment)
-------------------------------------------------------------------------
Every command below was typed by me while doing this assignment, in roughly
the order I used them. Next to each one is a short note on why I needed it.

[Setting up]
git init -b main
  -> Turned my plain folder into a repo. I passed -b main so the first branch
     is called "main" and not "master".

git status
  -> I ran this many times just to check where I was: which files Git was not
     tracking yet, what was modified and what was ready to commit.

[Saving work]
git add index.html about.html
  -> Put my two HTML pages in the staging area so they would go into commit #1.

git commit -m "..."
  -> Saved a snapshot. Message for each snapshot says what I changed.

git commit -am "..."
  -> Shortcut I used once: it stages every already-tracked file I edited and
     commits it, so no separate git add was needed.

git diff
  -> Before my 2nd commit I used this to see the exact line I added to
     index.html (the green + line).

[Branching]
git branch feature
  -> Made a new branch called feature starting at my latest main commit.

git branch
  -> Printed my branches; the star told me I was on feature.

git switch feature / git switch main
  -> Jumped between branches. My files on disk changed to match the branch.

git merge --no-ff feature -m "..."
  -> While on main, pulled the about.html change from feature into main.
     --no-ff forces a real merge commit so the fork is visible in the graph.

[Looking at history]
git log --oneline --graph --all --decorate
  -> My favourite one: every commit on one line, the branch fork drawn with
     | and \ symbols, plus labels showing where main and feature point.

git log --oneline -3
  -> Same idea but only the newest 3 commits, handy before and after undoing.

[Ignoring files]
cat .gitignore
  -> Printed my ignore rules: *.log (any log file) and temp/ (whole folder).

git status --ignored
  -> Proof that the rules work: app.log and temp/ are listed as ignored.

[Undoing]
git reset --hard HEAD~1
  -> Threw away my last (local, not pushed) commit. HEAD~1 means "one commit
     before now". --hard also wipes that change from the files.

git revert --no-edit HEAD
  -> The safer undo. Instead of deleting history it adds a new commit that
     reverses the previous one, so it can be used after pushing.

[GitHub]
gh repo create git-workflow-assignment --public --source=. --remote=origin
  -> Used the GitHub CLI to make a public repo on my account from this local
     folder and link it under the name origin. (Same as making an empty repo
     on github.com and then running git remote add origin <url>.)

git remote -v
  -> Double-checked that origin points to my GitHub repo URL.

git push -u origin main
  -> Sent main and all its commits to GitHub. -u remembers origin/main so a
     plain "git push" works next time.

git push origin feature
  -> Also uploaded the feature branch so it shows up on GitHub.
