GIT COMMANDS USED IN THIS ASSIGNMENT
====================================

1. git init -b main
   Creates a new empty Git repository in the current folder, with "main" as the default branch.

2. git status
   Shows which files are untracked, modified, or staged for the next commit.

3. git add <file>   (e.g. git add index.html about.html)
   Stages the given file(s) so their current content goes into the next commit.

4. git commit -m "<message>"
   Records the staged changes as a new commit in the history with a descriptive message.

5. git commit -am "<message>"
   Stages all modified tracked files and commits them in one step.

6. git diff
   Shows line-by-line changes in the working directory that are not yet staged.

7. git branch feature
   Creates a new branch named "feature" pointing at the current commit.

8. git branch
   Lists all local branches; the current branch is marked with *.

9. git switch feature   /   git switch main
   Moves HEAD to the named branch and updates the working files to match it.

10. git merge --no-ff feature -m "<message>"
    Merges the feature branch into the current branch (main); --no-ff always creates a merge commit so the branch activity stays visible in history.

11. git log --oneline --graph --all --decorate
    Displays the full commit history of all branches as a compact graph with branch labels.

12. git log --oneline -3
    Shows only the last 3 commits, one line each.

13. cat .gitignore
    Prints the .gitignore file, which tells Git to ignore *.log files and the temp/ folder.

14. git status --ignored
    Shows the files Git is ignoring (app.log and temp/), proving .gitignore works.

15. git reset --hard HEAD~1
    Undoes the last commit: moves the branch back one commit and discards that commit's changes (used for local, unpushed commits).

16. git revert --no-edit HEAD
    Undoes the last commit safely by creating a new commit with the opposite changes; history is kept, so it is safe for pushed/shared branches.

17. gh repo create <name> --public --source=. --remote=origin
    Creates a new public repository on GitHub (after the local repo already exists) and adds it as the remote "origin".
    (Equivalent without the GitHub CLI: create the empty repo on github.com, then run "git remote add origin <URL>".)

18. git remote -v
    Lists the configured remote repositories and their URLs to confirm the connection.

19. git push -u origin main
    Uploads the main branch and its full history to GitHub and sets origin/main as its upstream.

20. git push origin feature
    Uploads the feature branch to GitHub so the branch is visible there too.
